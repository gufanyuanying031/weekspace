# 使用指南

## 先收集，再安排

在右侧「随心安排」输入任务，回车加入。拖到日期和时段后，会创建一条独立任务，原模板保留。每次都可继续拖放；点模板右侧 × 可删除，底部可撤销。

点击格子中的添加直接输入，回车保存。点任务标题直接改字，点「…」编辑时间、日期或备注。已有安排也可拖到其他格子。课程实例移动后只改变这一次，不改变重复模板。

## 选择自己的工作周期

双指横滑或拖动日期栏可以平移七天。日期平时是静态文字，点击起始日才打开日历；「今天起」从今天开始，「本周」恢复当前周一至周日。

七日记录存放在 AI 工作台的「手写记录」。每个起始日分别保存；例如周三至下周二与周一至周日有各自的记录。AI 输入和 Markdown 导出跟随当前范围。

## 固定课表与导入

课表支持每周、单双周和指定教学周。单双周根据教学第 1 周计算；请先选对学期起点。

支持 `.xlsx`、UTF-8 CSV 和 TSV。常见列表表头为课程名称、星期、时段、开始时间、结束时间、教室、单双周。网格支持星期列、时段行和课程明细表；连续节次会合并，部分非连续周次及特殊星期会转为独立安排。

导入分为读取、识别、核对和确认。不会因为选择文件而覆盖已有计划。时间、教师或地点未知时，不应依赖 AI 推测；请自行核对。

文件限制：12 MB、20 张工作表、单表 1000 行 × 80 列和 6 万字预览。超过限制会提示。`.xls`、加密文件和 1904 日期系统工作簿需转换格式后使用。

## AI 工作台

- 手写记录：自动保存当前七天的内容。
- 七日复盘与工作汇报：根据真实记录生成可编辑草稿，确认后保存。
- 排程建议：结合课表、已有任务和任务池提出安排，逐项选择再加入。
- 拆解目标：把一个目标拆成小任务，加入任务池以便拖放。
- 负荷分析：查看安排是否集中；未记录耗时时不会把任务数量当精确工时。

打开设置填写兼容 Chat Completions 的基础地址、模型名称与 API Key。本地无鉴权服务可留空密钥。发送前可以预览文本。

## 桌面与归档

右上角小窗口图标打开独立桌面面板，主窗口收起。面板支持换日期、勾选和快速添加；图钉切换桌面层与置顶，箭头回到完整计划。

编辑即时保存，运行时定期检查跨天；休眠或退出期间的归档会在下次运行时补齐。无任务日期不生成空快照，后续补记不覆盖已归档快照。关闭主窗口后仍可从菜单栏恢复；退出应用也会退出桌面面板。
